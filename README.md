# OP/ED 鉴赏会 🎵

新番 OP/ED 鉴赏会的打分小工具：贴一个 B 站合集的 BV 号，自动拉取全部分 P，现场逐首打分（每人主观总评 + 维度参考分 + 收藏 + 全场/个人标签 + 短评），结束后一键生成带**争议指数**和**反差分析**的排行榜报告发群里。

## 评分体系（v2：总分独立，维度只是参考坐标）

这是给"有数十年阅历的资深听众"的小团体沙龙设计的，不是工业质检：

- **总分 = 主观总评**：每人独立给出（默认 1~10），工具**不会**用维度分加权算总分。"我知道它套路，但我就是不想给它高分"、"它制作糙，但情怀让我给满分"——这种反差正是沙龙的灵魂，均分说了不算，你说了算。
- **维度分 = 参考坐标系**，默认三维度（可改）：
  - **音乐本体 50%**：抽掉画面它还站不站得住——旋律、编曲、演唱本身的听感冲击（音乐本体中心性）
  - **音画定制 30%**：它是不是为这部番"长"出来的——应景、割切时机、与画面互文的定制完成度
  - **本格共鸣 20%**：真诚度探测——是表达还是套路糖精；糙但真情可以高分，精致但工业可以低分
- **反差 Δ = 主观总评 − 维度参考分**（按权重归一化换算）。工作台打分时实时显示，报告里逐人摊开：**正 = 情怀溢价，负 = 套路压分**。允许且鼓励脱节。
- **争议指数 = 大家总分的标准差**（≥ 跨度 18% 记 🔥）。让数据分析师一眼定位吵得最凶的曲子。
- **标签库**记录情绪证据：`工业糖精`、`拼好曲式-生硬`、`拼好曲式-浑然天成`、`本格anisong`、`神级应景`、`VOCALOID味`、`情怀暴击`、`反套路`、`制作糙但真情`……支持全场标签与**个人标签**、全场短评与**个人短评**。

> VOCALOID 化、拼好曲式这些只是**特征**，不是扣分项——最终落到"听感"和"是否应景"上，由每张主观总评票自己裁决。

### ✨ AI 锐评（DeepSeek，可选）

设置页填好 Base URL（默认 `https://api.deepseek.com`）、模型名（默认 `deepseek-flash`，若提示"模型不存在"改成 `deepseek-chat` / `deepseek-reasoner` 等官方名）和 API Key，用「测试连接」验证。

之后在工作台点 **「✨ AI 锐评」** 才会真正调用：把本场的聚合统计（榜单、争议指数、反差值、标签、短评）发给模型，生成含"本场亮点 / 争议焦点 / 反差解读 / 每人口味画像 / 一句话总评"的锐评，存进期次（保留最近 5 份），可一键复制发群。

- API Key 存在 `data/ai.json`（已 gitignore），不进 `config.json`、任何接口都不明文回传
- 生成时数据需发到所配置的服务商云端；默认可开「匿名化参与人」，模型只会看到 成员A/B/C
- 不配置 Key 完全不影响其它功能

## 使用（日常）

双击 **`启动鉴赏会.bat`**，浏览器打开 <http://127.0.0.1:18890> 即可。首次双击会自动安装依赖并构建（需要已装 Node.js LTS）。

一场鉴赏会的流程：

1. **设置页**：把同学（参与人）、打分维度（默认 音乐本体/音画定制/本格共鸣，权重可调）、标签库配好；顶部有评分体系的说明
2. **首页 → 新建一期**：贴 B 站分享链接（自动提取 BV 号），或手动粘贴曲目列表
3. **打分工作台**：左边分 P 列表，中间给当前曲打分——输完一格按回车跳下一格，最后一个回车自动进下一首；行尾 ★ 收藏；支持全场短评/标签、**🪞 反差注解**（每人个人标签 + 一句话，解释"为什么我给这个分"）、跳过（菜单类分 P）
4. **报告**：工作台或期次卡片一键「预览排行榜 / 下载 HTML / Markdown / Excel / JSON」。总榜带**争议**与**反差**列；还有「🔥 争议焦点」（逐人摊开评价构成）、「⚖️ 反差榜」（本格溢价 / 套路罚分 Top）、「🏷️ 标签情绪统计」；首页另有跨期「全期总榜」

### 线上鉴赏会（腾讯会议，不在同一 WiFi）

按方便程度三选一，可组合：

- **语音报分**（零配置）：你开着悬浮面板，大家会议里报分，你敲数字——最简单。
- **个人打分单**（零网络依赖）：期次卡片 `⋯` →「下载打分单（发同学）」，得到一个单文件网页；同学在自己电脑打开、点分、点**自己的情绪标签**、导出 JSON 发回来；你再 `⋯` →「导入打分单…」多选合并，新人名字自动加入配置，标签会并入报告的反差注解。
- **在线打分**（实时落库）：双击 `开远程打分.bat`（需先 `winget install --id Cloudflare.cloudflared` 装一次通道），把打印出的 `https://xxxx.trycloudflare.com` 网址发群里，同学浏览器打开即点即存。**用完 Ctrl+C 关掉**——窗口开着期间任何人拿到网址都能改数据。

### 悬浮打分面板（📺 悬浮面板）

工作台顶部的「📺 悬浮面板」用浏览器画中画窗口（Chrome/Edge 116+）弹出**始终置顶**的快速打分窗：只放总分 + 收藏 + 切歌。全屏看 B 站视频、开会共享屏幕时都能直接打分，不用切窗口。

### 网易云音乐关联（🎵 可选）

把分 P 关联到网易云曲库，试听原曲、本机重播收藏串烧。基于**网易云音乐开放平台官方 CLI**（个人开发者，`@music163/ncm-cli` 已在依赖里），凭证完全走 CLI 自己的配置文件，不进本仓库。

一次性配置（开发者后台拿到 App ID 和私钥后）：

```bash
npx @music163/ncm-cli config set appId <你的AppID>
npx @music163/ncm-cli config set privateKey <你的私钥内容>
npx @music163/ncm-cli login      # 扫码，歌单/每日推荐等用户级操作需要
winget install mpv               # 可选：本机播放用
```

之后在工作台：

- **🎵 关联网易云**：搜索当前曲（自动取「曲名／原文」里的原文 + 歌手做关键词，翻译名搜不到的原文能搜到），匹配结果缓存在这一期数据里
- **🎵 匹配网易云（N）**：批量匹配全部未关联的分 P（每天 5000 次额度，157 首全跑一遍也就 157 次）
- **试听 ↗**：网易云网页版打开这首歌；**▶ 本机**：CLI+mpv 本机播放

数据全部存在 `data/` 目录（JSON 文件），备份就是复制这个目录。

## 开发

```bash
npm install
npm run dev        # Express(18890) + Vite(5175，/api 代理)
npm run build      # 构建前端到 dist/
npm start          # 只起后端（同时 serve dist）
npm run typecheck  # vue-tsc 类型检查
node scripts/seed-demo.mjs   # 起服务后运行：注入演示数据（含四种反差场景）并生成全部报告样例
```

## 结构

```
server/           Express 后端
  index.js        API 路由 + 静态资源（含单曲级合并写入/打分单导入）
  bili.js         B站视频信息/分P代理（带缓存，data/cache/）
  parse.js        分P标题解析（先行/正式OP·ED、【主题曲】等模式）
  store.js        config / sessions JSON 存取（含沙龙三维度/标签库迁移）
  stats.js        榜单统计：反差值、争议指数、标签情绪（单期 + 跨期聚合）
  report-*.js     HTML / Markdown / Excel 报告生成（争议焦点/反差榜/标签统计）
  sheet.js        离线个人打分单（单文件 HTML，含个人标签）
src/              Vue3 + TS + Element Plus 前端
  views/HomeView.vue        期次列表 / 新建 / 打分单导入导出
  views/WorkbenchView.vue   打分工作台（权重表头、Δ 反差提示、🪞 反差注解）
  views/PipView.vue         悬浮置顶快速打分面板
  views/SheetView.vue       在线个人打分页（即点即存 + 个人标签）
  views/SettingsView.vue    参与人/维度权重/标签库/评分体系说明/AI 配置
data/             运行数据（gitignore）
启动鉴赏会.bat     日常启动
开远程打分.bat     可选：cloudflared 临时公网通道（在线打分）
```

## 说明

- B 站只调用公开的 `pagelist` / `view` 接口拉标题和时长，每期一次并缓存，无需登录；接口异常时可用「手动粘贴列表」导入，不耽误鉴赏会
- 分 P 标题解析是尽力而为（不同 UP 主格式不同），解析不对可在工作台「修正信息」里手动改
- 隐藏某个打分维度只是不显示，历史数据保留，随时可以再打开
- 旧数据自动兼容：老配置（编曲/vocal/画面）会在加载时升级为沙龙三维度，标签库合并进推荐标签；历史期次里的分数原样保留
