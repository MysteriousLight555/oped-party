# OP/ED 鉴赏会 🎵

新番 OP/ED 鉴赏会的打分小工具：贴一个 B 站合集的 BV 号，自动拉取全部分 P，现场逐首打分（每人主观总评 + 维度参考分 + 收藏 + 全场/个人标签 + 短评），结束后一键生成带**争议指数**和**反差分析**的排行榜报告发群里。

## 评分体系（v2：总分独立，维度只是参考坐标）

这是给"有数十年阅历的资深听众"的小团体沙龙设计的，不是工业质检：

- **总分 = 主观总评**：每人独立给出（默认 1~10），工具**不会**用维度分加权算总分。"我知道它套路，但我就是不想给它高分"、"它制作糙，但情怀让我给满分"——这种反差正是沙龙的灵魂，均分说了不算，你说了算。
- **维度分 = 参考坐标系**，默认三维度（可改）：
  - **音乐本体 50%**：抽掉画面它还站不站得住——旋律、编曲、演唱本身的听感冲击（音乐本体中心性）
  - **音画定制 30%**：它是不是为这部番"长"出来的——应景、割切时机、与画面互文的定制完成度
  - **本格共鸣 20%**：真诚度探测——是表达还是套路糖精；糙但真情可以高分，精致但工业可以低分
- **反差 Δ = 主观总评 − 维度参考分**（按权重归一化换算）。工作台打分时实时显示，报告里逐人摊开：**正 = 情怀溢价，负 = 套路压分**。允许且鼓励脱节。
- **争议指数 = 大家总分的标准差**（≥ 跨度 18% 记 🔥）。让数据分析师一眼定位吵得最凶的曲子。
- **标签库**记录情绪证据：`工业糖精`、`拼好曲式-生硬`、`拼好曲式-浑然天成`、`本格anisong`、`神级应景`、`VOCALOID味`、`情怀暴击`、`反套路`、`制作糙但真情`……支持全场标签与**个人标签**、全场短评与**个人短评**。

> VOCALOID 化、拼好曲式这些只是**特征**，不是扣分项——最终落到"听感"和"是否应景"上，由每张主观总评票自己裁决。

### ✨ AI 锐评（DeepSeek，可选）

设置页填好 Base URL（默认 `https://api.deepseek.com`）、模型名（默认 `deepseek-flash`，若提示"模型不存在"改成 `deepseek-chat` / `deepseek-reasoner` 等官方名）和 API Key，用「测试连接」验证。

之后在工作台点 **「✨ AI 锐评」** 才会真正调用：把本场的聚合统计（榜单、争议指数、反差值、标签、短评）发给模型，生成含"本场亮点 / 争议焦点 / 反差解读 / 每人口味画像 / 一句话总评"的锐评，存进期次（保留最近 5 份），可一键复制发群。

- API Key 存在 `data/ai.json`（已 gitignore），不进 `config.json`、任何接口都不明文回传
- 生成时数据需发到所配置的服务商云端；默认可开「匿名化参与人」，模型只会看到 成员A/B/C
- 不配置 Key 完全不影响其它功能

## 使用（日常）

双击 **`启动鉴赏会.bat`**，浏览器打开 <http://127.0.0.1:18890> 即可。首次双击会自动安装依赖并构建（需要已装 Node.js LTS）。

一场鉴赏会的流程：

1. **设置页**：把同学（参与人）、打分维度（默认 音乐本体/音画定制/本格共鸣，权重可调）、标签库配好；顶部有评分体系的说明。设置页的参与人是**新一期的默认成员**，每期还可以在「👥 成员」里单独增删
2. **首页 → 新建一期**：贴 B 站分享链接（自动提取 BV 号），或手动粘贴曲目列表；**⚡ 快速开始**更轻——临时三五首歌，粘贴框每行一首回车直接开评（单行粘 BV 号/分享链接也认），期次菜单可设「不计入全期总榜」隔离临时数据，工作台矩阵底部输入名字回车即可现场加人
3. **打分工作台**：左边分 P 列表，中间给当前曲打分——输完一格按回车跳下一格，最后一个回车自动进下一首；行尾 ★ 收藏；支持全场短评/标签、**🪞 反差注解**（每人个人标签 + 一句话，解释"为什么我给这个分"）、跳过（菜单类分 P）
4. **邀请朋友**：新建一期后电脑端会自动弹出邀请（也可在首页期次卡片或工作台顶部点「📨 邀请」），得到参与链接 + 二维码 + 房间口令。朋友打开后选名字、输口令即可在手机上打分；主持人页面不要发出去
5. **现场切歌**：在工作台点「📣 投影这首」，手机打分页会自动定位到这首，大屏显示"已提交 x/y、还差谁"。想减少互相影响就打开「独立评分」，大家交完再点「揭晓分数」
6. **结束与报告**：首页期次菜单「结束本场并锁定」，有漏评会先列出来（可强制结束）；结束后分数锁定、不能再改，想补分就「重新开放」。报告入口照旧：预览 / HTML / Markdown / Excel / JSON，总榜带**争议**与**反差**列；还有「🔥 争议焦点」、「⚖️ 反差榜」、「🏷️ 标签情绪统计」；首页另有跨期「全期总榜」

> 所有保存都是**按字段合并**的：朋友交分的同时，主持人改短评/标签也不会再把对方的分数覆盖掉。手机上会一直显示"保存中 / 已保存 / 保存失败待重试"，断网时修改先存在本地，联网后自动补交。

### 线上鉴赏会（腾讯会议 / 异地两人）

按方便程度三选一，可组合：

- **语音报分**（零配置）：你开着悬浮面板，大家会议里报分，你敲数字——最简单。
- **个人打分单**（零网络依赖）：期次卡片 `⋯` →「下载离线打分单」，得到一个单文件网页；同学在自己电脑打开、点分、点**自己的情绪标签**、导出 JSON 发回来；你再 `⋯` →「导入打分单…」多选合并，新名字会加入本场成员。
- **在线打分**（实时落库，推荐）：
  1. 双击 `开远程打分.bat`（需先 `winget install --id Cloudflare.cloudflared` 装一次通道），复制窗口里打印的 `https://xxxx.trycloudflare.com`
  2. 本机打开工作台 →「📨 邀请」→ 把公网网址填进「根地址」→ 复制参与链接/二维码发群里；房间口令一起发
  3. 朋友打开链接 → 选名字 + 输口令 → 手机点分即存；大屏和主持人工作台会自动同步
  4. **用完 Ctrl+C 关掉通道**。通道开着期间，拿到**参与链接**的人只能改自己的分数；主持人页面另有房间管理密钥保护，不会因为把根网址发出去就被朋友误进

### 权限（轻量，够熟人局用）

- **本机直连**（`127.0.0.1` / `localhost`）自动识别为主持人，日常不用登录
- 通过公网隧道或另一台设备打开**主持人页面**时，需要「房间管理密钥」（启动窗口会打印，也可在本机设置页复制）；在首页「我是主持人」里输入一次即可
- 朋友从参与链接加入后拿到只属于「本场 + 本人」的凭证，只能写自己的分数、标签和收藏；改配置、删期次、恢复备份、网易云账号等接口都只对主持人开放
- 每期有独立房间口令（4~8 位，可在邀请弹窗里改），加入时校验；口令防陌生人，不防熟人冒名，两个熟人局够用

### 悬浮打分面板（📺 悬浮面板）

工作台顶部的「📺 悬浮面板」用浏览器画中画窗口（Chrome/Edge 116+）弹出**始终置顶**的快速打分窗：只放总分 + 收藏 + 切歌。全屏看 B 站视频、开会共享屏幕时都能直接打分，不用切窗口。

### 网易云音乐关联（🎵 可选）

把分 P 关联到网易云曲库，试听原曲、本机重播收藏串烧。基于**网易云音乐开放平台**（个人开发者）直连 API：搜索走官方网关（RSA 签名），凭证全部存 `data/ncm-auth.json`（已 gitignore），不进仓库。

一次性配置：把开发者后台的 **AppID** 和**私钥**写进 `data/ncm-auth.json`（参考 `{ "appId": "...", "privateKey": "...", "deviceId": "ncmcli_任意hex", "clientIp": "你的公网IP" }`，deviceId/clientIp 首次留空也会自动生成）。

**登录**：设置页底部「网易云音乐 → 扫码登录」，把二维码链接发到手机用网易云 App 打开确认即可（token 24 小时有效，过期后匹配会提示重扫）。

之后在工作台：

- **🎵 关联网易云**：搜索当前曲（自动取「曲名／原文」里的原文 + 歌手做关键词），拿到明文 ID/加密 ID/专辑/封面缓存进当期
- **🎵 匹配网易云（N）**：批量匹配全部未关联的分 P（每天 5000 次额度）
- **试听 ↗**：`https://music.163.com/#/song?id=<明文ID>` 网页直接听
- **▶ 本机**：CLI+mpv 本机播放（可选，需另 `npx @music163/ncm-cli login` 扫码 + `winget install mpv`）

数据全部存在 `data/` 目录（JSON 文件），备份就是复制这个目录。

## 开发

```bash
npm install
npm run dev        # Express(18890) + Vite(5175，/api 代理)
npm run build      # 构建前端到 dist/
npm start          # 只起后端（同时 serve dist）

node scripts/verify-sync.mjs    # 保存时序回归（结束前保存、并发输入、手机离线与旧响应）

```

## 说明

- **设置分两层（快照式）**：全局设置是"模板"——新期次建期时会把当时的参与人/维度权重/标签/分值范围**快照**进这一期，之后改全局不影响已建的期。单期的人员变动、不同维度、权重调整在期次卡片「⚙ 本期设置」里改；跨期总榜按各期自己的权重算反差。存量期次没有快照的自动回落全局（行为与旧版一致）；「跟随全局」让本期维度、标签和分数范围使用全局模板，本场成员仍独立维护，邀请加入、内联加人和本期设置使用同一份名单
- **标题与链接解析是三层兜底**：① B 站分享文本自动提取 BV 号，`b23.tv` 短链自动跟随跳转；② 分P标题走正则解析（先行/正式 OP·ED、【类型】、插入曲/IN、番名「曲名」、番名 OP【曲名】等变体），解析不出就整标题当曲名；若视频简介里写了与分P数一致的曲目单，会自动按位置辅助补全；③ 还不够就点工作台「🤖 AI 识别标题」，把标题列表发给 DeepSeek 批量结构化——**只补空字段、不覆盖已解析和人工修正的内容**，且 prompt 禁止编造（不确定就留空）。最后一道防线永远是「修正信息」手动改
- **持续更新的合集**：「（持续更新中！！）」这类合集每周加歌——工作台「🔄 同步分P」重新拉取分P列表增量合并：已打的分/维度/标签/短评/收藏原样保留，新增分P按老规则解析，B站侧已删的分P不丢（挪到期末）。首页期次卡片有「⚠ N 首未识别」徽章提醒解析质量；工作台顶部也会在解析不完整时给出提示条
- B 站只调用公开的 `pagelist` / `view` 接口拉标题、封面、简介和时长，每期一次并缓存，无需登录；接口异常时可用「手动粘贴列表」导入，不耽误鉴赏会
- 分 P 标题解析是尽力而为（不同 UP 主格式不同），解析不对可在工作台「修正信息」里手动改
- 隐藏某个打分维度只是不显示，历史数据保留，随时可以再打开
- 旧数据自动兼容：老配置（编曲/vocal/画面）会在加载时升级为沙龙三维度，标签库合并进推荐标签；历史期次里的分数原样保留
