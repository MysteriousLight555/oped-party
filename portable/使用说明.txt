OP/ED 鉴赏会打分工具 · 便携版（win64）
========================================

免安装：不用装 Node、不用装任何依赖。

【本地使用】
  双击「启动鉴赏会.bat」，浏览器会自动打开 http://127.0.0.1:18890
  （关掉那个黑窗口 = 停止服务）

【线上鉴赏会（腾讯会议场景）】
  双击「开远程打分.bat」，窗口里会打印一个 https://xxxx.trycloudflare.com 公网网址，
  本机打开工作台，点「📨 邀请」，把这个公网网址填进「根地址」，
  再把参与链接或二维码和房间口令发给朋友。
  朋友打开后选名字、输入口令，即可打分；下次打开会记住身份。
  公网根网址进入朋友入口，主持人管理页另需启动窗口或设置页里的房间管理密钥。
  结束后关闭通道窗口。

【数据与备份】
  所有期次、打分记录都在 app\data\ 文件夹里，拷走即备份。
  也可在网页「设置」页一键导出/导入备份（设置页不含网易云凭据）。

【网易云音乐功能（可选）】
  需要网易云开放平台个人开发者凭证：在 app\data\ncm-auth.json 配置
  appId / privateKey / appSecret，然后在网页「设置」页扫码登录。
  不配置不影响打分、报告等全部核心功能。

【升级】
  新版本发布后，把新版 zip 里的 app\、node\、cloudflared\ 覆盖过来即可，
  app\data\ 不要覆盖（那是你的数据）。

版本：详见 GitHub Releases 页面
